Installation

System requirements

  • Linux host (x86_64) with a KVM-enabled CPU (Intel VT-x or AMD-V).
  • 4 GB RAM minimum, 8 GB+ recommended.
  • 20 GB+ free disk space for the OS; additional disks for VM storage.
  • Network access between all nodes and at least one controller.

Boot the kcore ISO

Download the kcore NixOS ISO and boot the target machine from it. The live environment starts a node-agent on port 9091 that accepts install commands from kctl.

Create a cluster (PKI & mTLS context)

On your operator workstation, initialise the cluster trust material. This creates a root CA, sub-CA, controller certificate, and kctl client certificate under ~/.kcore/<context>/.

kctl create cluster --name my-cluster

This is a one-time operation per cluster. The resulting files are used by every subsequent kctl command and by kctl node install to provision node certificates.

Connect kctl to the controller

After the first node is installed with --run-controller (see First cluster), point kctl at it:

kctl -s 192.168.40.105:9090 get nodes

For repeated use, pass -s (or --controller) with the controller address. Multiple -s flags are supported for HA failover — kctl tries each endpoint in order.

TLS modes

ModeFlagUse case
mTLS (default)noneProduction — mutual certificate verification.
Insecure-k / --insecureLocal dev only — plain HTTP, no certificates.

Never use --insecure outside of local development. All production traffic should use the cluster mTLS context created by kctl create cluster.
