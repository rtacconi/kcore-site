kcore follows an open-core model. The Community Edition source is available under the Apache License 2.0. Apache-2.0 does not restrict commercial use of the code you build from that tree; always read LICENSE for the exact terms.

Subscriptions cover services and artifacts around the project: the official supported distribution, stable production update channel, signed ISO images, tested releases, and commercial support. A subscription does not replace the open-source licence on the public core.
