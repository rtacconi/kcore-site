Windows Server 2022 on kcore

29 September 2026

← Back to blog

kcore runs guests on Cloud Hypervisor. Windows Server needs the Cloud Hypervisor UEFI firmware and Hyper-V CPU enlightenments (kvm_hyperv=on) on every VM. With those set, Server 2022 boots from a virtio disk and comes up on a virtio NIC.

IIS from the command line

IIS is an inbox feature. From an Administrator command prompt:

powershell -Command "Install-WindowsFeature Web-Server -IncludeManagementTools"

The page below is the stock IIS welcome site, served by that guest and opened from a workstation through a port forward to the VM.
