What matters when you leave VMware—not a feature wishlist

Atomic updates & rollback

NixOS under the hood: every host change is atomic. If an update breaks something, roll back in seconds. The host OS is immutable.

Windows guests

Run Windows Server and Windows desktop guests alongside Linux. Suitable for mixed estates leaving VMware.

GPU passthrough

Assign physical GPUs to VMs with VFIO passthrough. NVIDIA vGPU / SR-IOV support is under planning.

Multi-datacenter HA

Control-plane replication across datacenters with CRDTs, a Rust gRPC stack, and formal methods (including TLA+) for distributed behaviour.

How it works

A controller holds desired state; node agents run Cloud Hypervisor on each NixOS host; you operate the cluster with kctl and the same gRPC APIs.

  • ✓
    Immutable OS

    Built on NixOS. The host filesystem is read-only. Updates swap the entire system atomically.

  • ✓
    API-First

    gRPC all the way down. The CLI and Terraform provider are just API clients.

  • ✓
    Multi-Node

    Add nodes by booting the ISO and pointing them at the controller. They register automatically.

  • ✓
    Flexible Storage

    Local directories, LVM, or ZFS. Pick what makes sense for your hardware.
