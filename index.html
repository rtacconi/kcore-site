Three decisions this page is for

Pick the one that matches the renewal in front of you.

Hosting providers leaving VCSP

Current customer contracts can still run. New commitment contracts and renewals cannot. We assess the estate and quote a move onto kcore before the term ends.

On-prem estates facing a Broadcom quote

kcore is priced per CPU socket per year, not per core, and there is no 72-core order minimum. Compare that number with the renewal before you re-platform.

Sites where a bad update is an outage

Each host update is one transaction. If it fails, the machine boots the previous generation. That is the reason to look at kcore for retail, plant, and remote racks.

What you are actually buying

Outcomes a renewal conversation can use. Stack detail stays in the docs.

A failed update boots the last good host

Every host change is one transaction. If an update breaks the machine, it boots the previous generation. The host operating system is immutable.

Windows guests

Windows Server and Windows desktop guests run next to Linux. A mixed estate does not have to split platforms to leave VMware.

One physical GPU per VM

A physical GPU can be assigned to one VM. Licensed NVIDIA vGPU, where many VMs share one card, is not available yet.

Move VMs when the disk is shared

VMs move between hosts when their disks are on shared Ceph storage. The control plane can replicate across datacenters. This is not vSphere HA, and live migration needs Ceph.

Migration is a project, not a button

kcore-migrate inventories a vCenter or Proxmox estate and converts exported disks to qcow2 or raw. It does not pull disks straight from vCenter. Cutover of a whole estate is still a project.

Per socket, not per core

You pay per CPU socket per year. The evaluation ISO is free. There is no per-core meter and no 72-core minimum.

How it works

A controller holds desired state; node agents run Cloud Hypervisor on each NixOS host; you operate the cluster with kctl and the same gRPC APIs.

  • ✓
    Immutable OS

    Built on NixOS. The host filesystem is read-only. Updates swap the entire system atomically.

  • ✓
    API-First

    gRPC all the way down. The CLI and Terraform provider are just API clients.

  • ✓
    Multi-Node

    Add nodes by booting the ISO and pointing them at the controller. They register automatically.

  • ✓
    Flexible Storage

    Local directories, LVM, or ZFS. Pick what makes sense for your hardware.
